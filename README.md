# AlphaOracle

Backend de ML para previsibilidade de mercado (principais bolsas de valores).

## Pré-requisitos

- Python 3.13+
- [Poetry](https://python-poetry.org/docs/#installation)

## Desenvolvimento

- **Instalar dependências:** `poetry install`
- **Ativar ambiente:** `poetry shell`
- **Rodar comando no ambiente:** `poetry run <comando>` (ex.: `poetry run pytest`)
- **Adicionar dependência:** `poetry add <pacote>` (produção) ou `poetry add --group dev <pacote>` (desenvolvimento)
